🚀 Supervised Learning Journey – Summer 2025

Welcome to my Supervised Learning Proof-of-Work Repository 🎯

This repo is my personal learning playground where I explored, implemented, and practiced everything I learned under Supervised Machine Learning during Summer 2025.
Instead of making one “perfect” notebook per algorithm, I chose to experiment multiple times — different datasets, different approaches, different tweaks. Because real learning happens when you build, break, and rebuild.

📌 What’s Inside?

This repository contains:

✅ Supervised ML algorithms (Regression & Classification)

✅ Multiple projects per algorithm (different datasets & problem statements)

✅ Jupyter notebooks & scripts with hands-on implementations

✅ Mini-README inside each algorithm folder documenting:

Intuition & math behind the algorithm

Key learnings from each project

A summary for quick revision

To document my ML journey instead of leaving files scattered on my laptop
